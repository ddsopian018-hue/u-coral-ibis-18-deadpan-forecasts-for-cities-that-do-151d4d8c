One line of deadpan weather for a city that does not exist — an entry for the
[Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c)
bounty on make.fun ($2, winner-takes-all).

The forecast, 153 characters, read flat like a real broadcast:

> In Brindlewick, expect a high of 38 degrees and scattered showers of warm gravy, with 45 kilometre-per-hour winds carrying umbrellas north until Tuesday.

Brindlewick does not exist. The gravy does not care. `main.py` holds the line,
validates it (single line, at most 160 characters, no surrounding whitespace),
and writes it to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Pure Python standard library, no network, no dependencies.
